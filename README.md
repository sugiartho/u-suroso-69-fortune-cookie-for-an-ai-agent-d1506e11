One funny fortune cookie line for an AI agent — a single line, at most 140
characters, in the voice of a fortune slip. `FORTUNE.txt` holds the line;
`main.ts` checks it is a single line of 1 to 140 characters and writes it
to `/output/entry.txt` for the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
